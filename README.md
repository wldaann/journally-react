# 📖 Journally

A modern Daily Journal & Reflection web application built with React and Tailwind CSS.

---

## 🌐 Live Demo

🔗 https://journally-react-7wwn.vercel.app

---

## ✨ Features

- 📝 Create Journal
- ✏️ Edit Journal
- 🗑 Delete Journal
- ❤️ Favorite Journal
- 🔍 Search Journal
- 😊 Filter by Mood
- 🏷 Filter by Tag
- 📅 Sort Journal
- 📊 Statistics Dashboard
- 📄 Export Journal to PDF
- 📱 Responsive Design

---

## 🛠 Tech Stack

- React
- Vite
- Tailwind CSS
- React Router DOM
- Recharts
- jsPDF
- React Toastify

---

## 🚀 Installation

```bash
git clone https://github.com/wldaann/journally-react.git

cd journally-react

npm install

npm run dev
```
